说明

怎么参加

三分钟读完，照着做就行

本站没有账号系统、没有登录框。报名和投稿都发生在 GitHub 上——你的 GitHub 账号就是身份，Issue 就是报名表，Pull Request 就是投稿。

这是什么

每期一个题目，一个截止时间，一个奖励。达到门槛的投稿数量后，悬赏才算成立；然后评审，选出一人兑现。

规则和大多数众包不同的一点：门槛看的是投稿数，不是报名数。 报名只是告诉我们有多少人在看，真正让悬赏成立的，是有人交出东西。

谁能参加

在校的计算机、软件、数学、统计、经济等相关专业学生。

这条不是摆架子。我们办这个站，是为了给真的需要 AI 工程能力的人做训练——不是卖提示词课，也不是拿「再不学 AI 就被淘汰」去营销。

限定在校学生，是因为你们有几年的完整时间去建立这套能力，而这正是三小时速成课给不了的东西。

已毕业，或者在读其他专业但确实在做这方面工作的，可以联系我们单独沟通；默认不参与评奖。

难度等级

每期标一个等级。选级请按「我现在能做到什么」来选，不是按奖金。

等级你应当已经能做到对应训练
L1 基础用命令行、装过 Python 包、看得懂英文文档环境搭建、工具链、调试
L2 进阶独立调通过环境、调过 API、写过 300 行以上工程化、交付、代码质量
L3 挑战读过源码、处理过生产环境的问题系统设计、处理不确定性

题目的差别不在「难不难」，在步骤给不给：L1 会写清怎么做，L3 只给约束，剩下的靠你自己查。

允许跨级报名。评审不会因为你是低年级就放宽标准，也不会因为你高年级就默认你该做得更多。

如何报名

  1. 在当期悬赏页点我要报名，浏览器跳到 GitHub
  2. 没登录的话，GitHub 会先跳到登录页，登录后自动回到这张表单
  3. 没账号的话，先注册一个（免费，五分钟）——这是参加的唯一门槛
  4. 表单顶部有一段说明，下面是期号、你打算怎么做，以及三组必须逐项勾选的确认（阅读、资格、承诺）
  5. 点 Submit new issue，完成

提交后你会得到一条属于你的 Issue。它同时是三样东西：报名记录、通知渠道（在下面回复，你会收到 GitHub 邮件）、以及评审时的上下文。

一期内每人只开一条 Issue。重复的会被手动关闭，不影响报名结果。

报名不收费、不绑定义务。但如果最后没交东西，不会计入门槛。

如何投稿

  1. 把你的作品放在你自己的公开仓库里，写一份三分钟能跑起来的说明
  2. 提一个 Pull Request，新增文件 _submissions/期号/你的GitHub用户名.md
  3. 正文里放两个链接：代码仓库、演示地址。说明一段话讲清你做了什么

不要提交二进制文件——图片、压缩包、视频一律给外链。文件名必须是你的 GitHub 用户名，这是唯一的去重手段。

常见问题

  • 可以组队吗？ 默认个人。组队请在报名 Issue 里写明成员，奖励按一份计。
  • 可以用现成的库吗？ 可以。但题目里点名要自己写的部分，必须自己写。
  • 晚一分钟算吗？ 以 PR 的创建时间为准，不看推送时间。
  • 落选的作品归谁？ 归你。本站不主张任何权利，也不会二次使用。
  • 可以连续参加多期吗？ 可以，每期单独报名。
  • 为什么一定要用 GitHub？ 因为身份、时间戳、记录都在那里，而且公开可查——不需要信任任何一方。
  • 没有 GitHub 账号怎么办？ 注册一个，五分钟。这是参加的唯一门槛。
