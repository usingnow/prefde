## 题目

Odoo 18 和 20 的官方安装文档不是一个版本。请把两份文档的差异整理成**结构化数据**，供后续的安装 Agent 直接读取。

至少覆盖这 8 个主题：

- Python 版本
- 系统依赖包（apt 包名）
- PostgreSQL 版本要求
- wkhtmltopdf 的要求
- 启动命令
- 配置文件位置
- 数据目录
- 从上一版本升级时的注意事项

## 交付

一份 `diff.json`，结构固定：

```json
{
  "versions": ["18.0", "20.0"],
  "entries": [
    {
      "topic": "python",
      "v18": "Python 3.10 及以上",
      "v20": "Python 3.12 及以上",
      "source": "https://www.odoo.com/documentation/18.0/administration/install.html",
      "quote": "原文摘录，10–40 字"
    }
  ]
}
```

外加一份 `diff.md`，同样的内容换成能读的形式。

**每条都要有 `source` 和 `quote`。** 没有引用的条目不算数。

## 验收

| 检查 | 判据 |
| --- | --- |
| JSON 合法 | `python3 -m json.tool diff.json` 通过 |
| 条目数 | `entries` ≥ 8，`topic` 不重复 |
| 引用真实 | 随机抽 3 条，URL 能打开，页面里能找到 `quote` |

## 评审标准

| 维度 | 权重 | 看什么 |
| --- | --- | --- |
| 覆盖度 | 40% | 8 个主题齐不齐，有没有漏掉重要的差异 |
| 引用准确 | 40% | 引用是否真的支撑那条结论 |
| 可读性 | 20% | `diff.md` 能不能让人三分钟看懂 |

## 规则

- 参与者须为在校学生（计算机 / 数学 / 统计 / 经济等相关专业），报名时确认
- 只能引用官方文档（`odoo.com/documentation`），不要用博客、教程、论坛
- 每人限交一份，截止前可以改
